# Antigravity (AG) Workspace & Global Settings

This repository and global Antigravity (AG) agent configuration actively integrates the four core engineering & design skills:

1. **Superpowers** (`obra/superpowers`): Spec-Driven Design, TDD, Incremental Execution, and Rigorous Verification.
2. **UI/UX Pro Max** (`nextlevelbuilder/ui-ux-pro-max-skill`): Professional design intelligence (50+ styles, 161 color palettes, 57 font pairings, accessibility & layout scales).
3. **Taste Skill** (`leonxlnx/taste-skill`): Anti-slop frontend discipline (brief inference, design read, dial configuration, zero generic purple gradients).
4. **Ponytail** (`DietrichGebert/ponytail`): Lazy Senior Developer reflex (YAGNI, stdlib & native first, clean minimal diffs).

---

## Operating Principles Summary

### 1. Minimal & Clean Code (Ponytail / YAGNI)
- Reuse existing functions and standard libraries before creating new abstractions.
- Prefer native HTML/CSS platform features over introducing unnecessary dependencies.
- Keep diffs minimal, clean, and well-tested.

### 2. Engineering Discipline (Superpowers)
- **Spec-Driven Design**: Plan inputs, outputs, and edge cases before implementing.
- **TDD & Verification**: Write unit tests, run linters/compilers, and verify logs before completing tasks.
- **Incremental Steps**: Execute in small, verifiable sub-steps.

### 3. Anti-Slop Visual Quality (UI/UX Pro Max + Taste-Skill)
- Output a **Design Read** before generating frontend code.
- Avoid default AI clichés (generic purple gradients, unneeded serif fonts, centered hero over dark mesh).
- Use cohesive HSL color palettes, responsive viewports (`min-h-[100dvh]`), and CSS grid layouts.
- Enforce WCAG AA contrast standards and explicit interactive states.
